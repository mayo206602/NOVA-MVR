# NOVA MVR Web Client

Статический веб-клиент по мотивам `Executive Summary.pdf`. Текущий фокус: только фронтенд, удобный для телефонов и готовый к публикации на обычном статическом хостинге.

## Что уже есть

- Стартовый экран только с двумя действиями: `Вход` и `Ввести ключ`
- Демо-админ с управлением ключами и редактированием других пользователей
- Генерация Steam-style ключей на 5 аккаунтов
- Назначение главного аккаунта по схеме `ключ -> owner account`
- Owner-модель: владелец ключа создает рабочие и семейные аккаунты внутри лимита
- Отдельные пространства `Work` и `Family` с раздельными задачами, календарями, заметками и чатами
- Семейный opt-in/opt-out для общего семейного календаря при приглашении
- Хранение состояния в `localStorage`
- `manifest.webmanifest` + `service worker` для installable/offline-ready режима

## Демо-доступ

- Админ: `admin`
- Пароль: `Admin#NOVA2026`

## Запуск локально

Подойдет любой статический сервер.

```bash
python3 -m http.server 4173
```

После этого откройте `http://localhost:4173`.

## Публикация

Можно без сборки выложить содержимое этой папки на:

- Vercel
- Netlify
- Cloudflare Pages
- GitHub Pages
- обычный Nginx/Apache-хостинг

Главное условие: раздавать файлы как статику и не блокировать `service worker`.

## Ограничения текущей версии

- Нет бэкенда, авторизации и синхронизации между устройствами
- Все данные хранятся только в браузере пользователя
- Приглашения реализованы как локальное создание аккаунтов владельцем, без email/SMS
- Ключи и аккаунты пока существуют только в пределах одного браузерного хранилища
